# V15.1 review scope

Review the five-round launch lifecycle, registered participant Lockers, exact
fee/treasury/liquidity accounting, failed-launch refund rights, complete
settlement before pool creation, permanent LP custody, and creator vesting.
Also review wallet target authentication, chain checks, deployment configuration,
and reproducible compiler outputs.

The three original V15 findings are explained in [V15_FINDINGS.md](./V15_FINDINGS.md).
Current rules are in [the technical reference](../docs/CONTRACTS_TECHNICAL.md).
Contract source, tests, pinned dependencies, ABIs, and build inputs are included.
The original private working evidence and Git history are not part of this export.

No independent audit approval is implied. Historical test results cannot replace
fresh reproduction of the selected source or a signed public-testnet lifecycle.
