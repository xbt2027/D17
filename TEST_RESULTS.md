# Test evidence scope

This sharing export includes executable contract and application tests. The
original execution logs are intentionally not included. Prior local test claims
are historical; the export itself is not a new execution of the full test suite.

Use the commands in README.md to reproduce tests. Record the new source commit,
tool versions, command exit status, and results before relying on any new run.
No real-chain deployment, wallet signing, or independent audit acceptance is
claimed by this document.
